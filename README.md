# 🌬️ Savonius 3D — Renewable Energy Simulation

Simulação tridimensional e interativa de uma **turbina eólica Savonius de eixo vertical**, desenvolvida para demonstrar visualmente os princípios de conversão da energia do vento em energia elétrica.

O projeto permite explorar a estrutura da turbina, controlar a intensidade do vento, acompanhar a rotação das pás e visualizar a geração de energia por meio de uma lâmpada virtual.

---

## 📌 Sobre o projeto

O **Savonius 3D** é uma aplicação educacional que utiliza recursos de modelagem e animação tridimensional para apresentar o funcionamento de uma turbina eólica de eixo vertical.

Por meio de uma experiência interativa, o usuário pode observar como o movimento do vento provoca a rotação das pás, como essa rotação é transmitida pelo eixo e como o sistema representa a conversão de energia mecânica em energia elétrica.

A proposta é tornar o aprendizado sobre energia renovável mais visual, acessível e interativo.

## 🎯 Objetivos

- Demonstrar o funcionamento de uma turbina eólica Savonius.
- Apresentar os principais componentes de uma turbina de eixo vertical.
- Simular a influência da intensidade do vento na rotação das pás.
- Representar visualmente a transmissão mecânica e a geração de energia.
- Proporcionar uma experiência de aprendizagem interativa em ambiente 3D.

## ⚙️ Funcionalidades

- **Visualização 3D:** representação tridimensional da turbina e seus componentes.
- **Simulação do vento:** representação visual do fluxo de ar.
- **Controle de intensidade:** ajuste da intensidade do vento.
- **Rotação das pás:** movimentação animada conforme os parâmetros da simulação.
- **Representação do gerador:** visualização da transmissão mecânica.
- **Fluxo de energia:** representação visual da energia até a lâmpada.
- **Lâmpada interativa:** alteração da iluminação conforme o funcionamento simulado.
- **Controles de simulação:** iniciar, pausar, parar e reiniciar.
- **Exploração técnica:** identificação dos componentes da turbina.
- **Modo educativo:** explicação das etapas de funcionamento do sistema.

## 🧠 Como funciona a simulação?

O funcionamento é apresentado em cinco etapas:

1. **Entrada do vento:** o fluxo de ar atinge as pás da turbina.
2. **Rotação das pás:** a ação do vento provoca o movimento do rotor.
3. **Transmissão mecânica:** o eixo transmite o movimento rotacional.
4. **Geração de energia:** o gerador representa a conversão de energia mecânica em elétrica.
5. **Iluminação:** a lâmpada demonstra visualmente o resultado da geração simulada.

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Git instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/savonius-3d-renewable-energy.git
```

### 2. Acesse a pasta

```bash
cd savonius-3d-renewable-energy
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
npm run dev
```

### 5. Acesse no navegador

```text
http://localhost:5173
```
