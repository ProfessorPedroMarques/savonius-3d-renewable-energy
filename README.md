# savonius-3d-renewable-energy
Simulação 3D interativa de uma turbina eólica Savonius, desenvolvida com React e Three.js. Demonstra visualmente o funcionamento da energia eólica por meio da movimentação das pás, fluxo de vento, transmissão mecânica e geração de energia para iluminação de uma lâmpada. Projeto educacional com visualização tridimensional e recursos interativos.
